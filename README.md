# Oxyvo VPN

Android VPN-клиент (Kotlin + Jetpack Compose) на ядре Xray в зелёном стиле.

- VLESS (TCP / WS / gRPC, TLS, Reality), VMess, Trojan
- Загружает публичные списки серверов из нескольких GitHub-источников, проверяет доступность и сохраняет до 100 быстрых серверов
- Автоподключение выбирает сервер с лучшим пингом из предпочтительной группы; отдельная кнопка подключает выбранный сервер
- Группы серверов «Белый список» и «Чёрный список» можно назначать вручную; предпочтительную группу можно выбрать в настройках вкладки «Серверы»
- Свои подписки и ссылки `vless://` `vmess://` `trojan://`
- **Б.С.** (белый список приложений): через VPN идут только выбранные приложения
- **Ч.С.** (чёрный список): выбранные приложения идут в обход VPN

## Сборка APK без Android Studio

1. Залейте содержимое проекта в репозиторий GitHub.
2. **Actions → Build APK → Run workflow**.
3. Скачайте APK из **Artifacts**.

Воркфлоу сам скачивает ядро `libv2ray.aar` из 2dust/AndroidLibXrayLite.
