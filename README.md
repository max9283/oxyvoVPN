# Oxyvo VPN

Android VPN-клиент (Kotlin + Jetpack Compose) на ядре Xray в зелёном стиле.

- VLESS (TCP / WS / gRPC, TLS, Reality), VMess, Trojan
- Сам загружает публичные списки серверов с GitHub, проверяет пинг и оставляет самые быстрые
- Свои подписки и ссылки `vless://` `vmess://` `trojan://`
- **Б.С.** (белый список): через VPN идут только выбранные приложения
- **Ч.С.** (чёрный список): выбранные приложения идут в обход VPN

## Сборка APK без Android Studio

1. Залейте содержимое проекта в репозиторий GitHub.
2. **Actions → Build APK → Run workflow**.
3. Скачайте APK из **Artifacts**.

Воркфлоу сам скачивает ядро `libv2ray.aar` из 2dust/AndroidLibXrayLite.

## Если списки серверов «протухли»

Источники серверов — чужие публичные репозитории, они могут исчезнуть или перестать обновляться.
Защита:
- Приложение хранит последние найденные рабочие серверы и пропускает мёртвые источники.
- Файл `sources.json` в корне вашего репозитория можно менять на GitHub **без пересборки APK**:
  добавляйте новые списки (`"cat": 1` — против белых списков, `"cat": 2` — против чёрных, `"mirrors"` — зеркала).
  Приложение подхватит его при «Обновить список». Адрес файла задан в `Defaults.REMOTE_SOURCES`
  (по умолчанию `max9283/oxyvoVPN`, поменяйте, если репозиторий называется иначе).
- Ядро Xray: после первой удачной сборки скачайте артефакт `libv2ray-core` из Actions и положите
  `libv2ray.aar` в `app/libs/` репозитория — сборка зафиксирует версию ядра и не сломается от его обновлений.

## Выпуск версии v1.0

```
git tag v1.0 && git push --tags
```
или на GitHub: Releases → Draft a new release → тег `v1.0`. APK прикрепится к релизу автоматически.
